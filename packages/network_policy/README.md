# Network Policy Manager 0.1.0 (MAS app, proposal/inspection only)

Independent Core + app, no imports from JediControl, Network Fabric, WireGuard or Noosphere. `network_policy.proposal` returns canonical proposed bilateral approval requests. It DOES NOT sign requests, persist policies, install peers, or grant OS/network access. Side owners sign externally, using separately held Ed25519 private keys. `network_policy.inspect` reads a bounded operator-selected existing `network-fabric-state-v1` file, validates matching source and destination signatures, exactly one non-ambiguous grant for each side, expiry, exact request and expected revision. Trust MUST come from local operator state, never caller input. Every verdict contains `needsEnforcement:true`; a good cryptographic verdict is NOT an open firewall port.

Raw UI fallback is included. CLI ports are manifest defaults only; installed lifecycle must preserve/resolve service port dynamically. No privilege elevation or network configuration actions. `proposalHash` identifies an unsigned proposal, not a signature on the proposal itself; source/destination sign `network-fabric-approval-v1` payloads, intentionally compatible with Network Fabric v0.3. Endpoints: authenticated `GET /graph`, `POST /invoke`; loopback `GET /health`. Unit tests run with Node 22. A Core+App integration test can be run in the full Adamantium checkout.
