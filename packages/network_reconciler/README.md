# Network Reconciler Preview 0.1.0 (MAS app)

Standalone Core + app. No runtime dependency on JediControl, Policy Manager, Network Fabric, Noosphere, WireGuard CLI or arbitrary system commands. Uses an operator-provisioned `NETWORK_RECONCILER_STATE` snapshot (`network-reconciler-state-v1`) with `node`, `revision`, `protectedIds`, `current:{routes:[],rules:[]}`. `network_reconciler.preview` compares canonical sorted, strictly validated desired config to current. It returns structured diff, revision/hash, blockers for protected IDs, newly allowed traffic and connectivity risks. It NEVER applies changes, even when blocker list is empty. `network_reconciler.rollbackPreview` checks a plan hash against current snapshot/revision and returns a hypothetical inverse only. No shell, network calls, firewall write, route write, key generation or persistence is included.

This is a *planning* API; it is not a privileged Reconciler or enforcement. Before any future real apply, a separate privileged provider, per-node management keepalive, external watchdog and revert timer, authority proven on both sides, atomic backups and human acknowledgement are mandatory. Versioned plan IDs are for traceability, not permission. Unit tests run on Node22 and isolated Core+App smoke runs in GitHub Actions against the MCP bridge feature branch.
